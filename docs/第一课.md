# 第一课：先理解回测报告里的五个词

## 1. 收益率

价格从100变成110，收益率是 `(110 / 100) - 1 = 10%`。价格再从110跌回100，
跌幅约为9.09%，所以涨跌百分比并不对称。

## 2. 复利

每一期的收益都会作用在上一期的新本金上。回测净值使用每日收益连续相乘，而不是
把每日百分比简单相加。

## 3. 最大回撤

最大回撤衡量历史上从某个净值高点跌到后来低点的最深幅度。它更接近“过程中最难受
的时候亏了多少”，应当先于收益率阅读。

## 4. 风险与收益

高历史收益不等于低风险，也不保证未来继续。至少要同时观察波动、最大回撤、交易次数
和样本外结果。

## 5. 复权

股票或基金发生分红、送转等事件后，价格序列需要调整才能比较长期变化。不同复权方法
回答的问题不同。本项目第一阶段使用不复权数据，并明确标注这一限制。

## 本项目如何避免最常见的作弊

均线信号使用当天收盘价计算，但最早在下一交易日开盘执行。程序通过 `shift(1)` 实现
时间延迟，并有自动测试检查。交易发生时还会扣除预设成本。
