# 账本结构与跨平台验收

## 受支持账本

当前 schema 为 2。版本 1 可在事务内升级至 2；未来版本、未知版本、重复版本、存在账本但缺少/清空版本记录均拒绝。
新项目没有账本表时，正常创建当前结构。当前版本声明不再授权自动修补损坏表。

结构契约根据本程序的标准 DDL 在隔离内存数据库生成，核验全部账本字段的类型、空值、默认值以及主键、唯一和 CHECK 约束。
未知字段/表不被静默删除；错误数值类型不被隐式转换。行情表不属于账本迁移范围。
旧版本的分红权益字段缺失或可空属于已知兼容路径，迁移后是非空 `[]`；其他不兼容结构拒绝。
既有版本 1 的只含状态缓存的兼容测试仍保留，但这种片段不等同完整可恢复账本，恢复审计仍检查完整表集合及账户关系。

完整非空 v1 账本在提交迁移之前，还必须通过事件哈希链、事件重放、账户归属及现金/份额/权益一致性审计。
任何 DDL、数据复制、结构校验或事件审计异常都回滚，保留旧版本和原有历史内容。

## 使用边界

此次没有对真实用户账本执行迁移。先关闭写入程序、保存原材料，使用独立副本验证迁移。
只读恢复流程不会自动升级旧账本；原版本材料保留，使用对应版本程序或在独立副本中显式验证升级后再重新准备材料。
不要删除 WAL、版本记录、事件或状态标记来绕过失败。
恢复材料、候选验收、人工切换和回退见[恢复验收与研究会话](恢复验收与研究会话.md)。

## 文件名验收

`finance-lab filename-audit` 只核验候选整理文件名称及对象类型，不读取行情内容、不改名、不修复。
风险包括大小写、Unicode 规范化、Windows 尾随点/空格别名，以及符号链接/重解析点。
目录自身及祖先中的链接也拒绝。通过文件名审计不代表行情内容健康。
