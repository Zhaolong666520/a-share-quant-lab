# 第二课：为什么必须看样本外结果

## 开发期与样本外期

开发期用来形成想法、写程序和选择固定参数；样本外期用来模拟“策略完成后面对未知市场”的
表现。样本外数据一旦被反复查看并用于修改参数，它就不再是真正的样本外数据。

本项目固定使用：

- 2018年至2022年：开发期；
- 2023年至最新数据：样本外期；
- 均线参数：20日和60日；
- 单边成本假设：5个基点。

程序不会根据样本外结果自动寻找更好的参数。

## 如何阅读报告

阅读顺序建议如下：

1. 先看样本外最大回撤；
2. 再看样本外策略是否优于买入持有基准；
3. 对比开发期和样本外期是否明显退化；
4. 查看交易边数，判断结果对成本是否敏感；
5. 打开交易流水，确认买卖都发生在信号形成后的下一交易日。

## 样本外盈利也不能证明策略有效

一次切分只覆盖有限的市场环境。即使样本外盈利，仍可能来自运气、特定行情或遗漏的现实交易
约束。后续还需要滚动切分、不同资产验证、停牌与涨跌停处理，以及更保守的成本假设。

## 本阶段不做的事情

- 不根据报告反复修改20日和60日参数；
- 不连接券商；
- 不把回测收益当作未来承诺；
- 不因为样本外亏损而删除或隐藏实验。
