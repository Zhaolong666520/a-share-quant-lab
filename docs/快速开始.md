# 新手快速开始：生成第一份离线报告

这是一篇面向零基础用户的操作教程。目标是在 10 分钟内生成并打开第一份 A-Share Quant Lab 报告，同时确认 Python 环境和项目入口工作正常。

本教程只运行固定合成数据，不下载真实行情、不连接券商、不读取账户信息，也不用于判断任何证券是否值得买卖。首次安装依赖需要访问 Python 软件包源，生成报告本身不访问行情源。

## 完成后会得到什么

运行成功后，`outputs/` 中会出现：

| 文件 | 用途 |
| --- | --- |
| `demo_000300_sma_report.html` | 可在浏览器中打开的中文报告 |
| `demo_000300_sma_equity.png` | 策略与买入持有基准的净值曲线 |
| `demo_000300_sma_metrics.json` | 适合程序读取的完整指标 |

演示使用固定种子的 899 个合成观察值。当前版本中，20/60 双均线累计收益约为 41.96%，同期合成买入持有约为 91.33%。这些数字只用于确认结果可复现；合成数据上的表现没有投资含义。

## 准备环境

需要 Python 3.11、3.12 或 3.13。推荐 Python 3.12。

可以使用 Git 克隆仓库，也可以从 GitHub Release 下载源码 ZIP。解压 ZIP 后，在项目根目录运行下面与你的系统对应的入口。

## Windows：双击运行

1. 双击项目根目录的 `run_demo.cmd`。
2. 第一次运行会创建 `.venv` 并安装锁定依赖，请等待窗口显示报告路径。
3. 打开 `outputs\demo_000300_sma_report.html`。

也可以在 PowerShell 中运行：

```powershell
.\run_demo.cmd
```

## Linux 或 macOS：运行 shell 入口

在终端进入项目根目录，然后运行：

```sh
sh run_demo.sh
```

使用 Git 克隆且文件保留可执行权限时，也可以运行：

```sh
./run_demo.sh
```

打开报告：

```sh
# macOS
open outputs/demo_000300_sma_report.html

# Linux 桌面
xdg-open outputs/demo_000300_sma_report.html
```

在没有桌面环境的服务器上，可以把 HTML 和 PNG 下载到本地再查看。

## 确认结果正确

报告顶部必须显示“合成演示数据”警告，数据来源必须是 `SYNTHETIC_DEMO_NOT_MARKET_DATA`。如果报告把数据描述为真实行情，请停止使用并提交 Issue。

曲线和指标在相同版本中应保持一致。微小的 PNG 文件哈希差异可能来自绘图库或字体环境，但 JSON 中的策略指标应保持一致。

## 常见问题

### 提示找不到 Python 3.11–3.13

安装 Python 3.12，重新打开终端后再次运行。若项目中已经有错误版本创建的 `.venv`，删除该目录后重试；不要删除项目的 `data/`、`experiments/` 或其他目录。

### Linux/macOS 提示 Permission denied

直接使用不依赖可执行权限的入口：

```sh
sh run_demo.sh
```

### 安装依赖失败

首次运行需要下载 Python 依赖。检查网络和软件包源后重新运行即可；脚本会复用已创建的 `.venv`。

### 报告没有自动打开

脚本只生成报告并打印路径，不会强制启动浏览器。手动打开 `outputs/demo_000300_sma_report.html` 即可。
