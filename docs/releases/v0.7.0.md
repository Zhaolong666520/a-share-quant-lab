# A-Share Quant Lab v0.7.0

这一版把项目从“能跑回测”推进到“能解释这次实验到底用了什么数据、什么账户约束，以及每一分钱能否对上”。

## 主要新增

- **数据集清单**：为整理数据计算 SHA-256 与稳定数据集 ID，并记录来源、日期区间、复权方式、成交量单位、采集时间和陈旧状态。
- **账户账本**：支持初始现金、100 份整手、最低佣金、卖出费用与滑点，逐日核对现金、份额、费用和权益。
- **完整压力测试链**：固定切分、walk-forward、成本敏感性、参数敏感性和执行可行性报告。
- **研究纪律**：保留落后基准和亏损实验，明确区分合成数据、事后代理与真实行情。
- **学习与协作**：七节中文课程、Windows 一键脚本、CI、Issue 模板、贡献指南与 MIT License。

## 示例结论

实验 006 的固定 20/60 双均线在对应数据和假设费用下得到 **-12.84%**，买入持有为 **+14.43%**。项目保留这个结果，因为研究流程是否诚实，比一条漂亮曲线更重要。

## 已知边界

- 日线阻塞条件是收盘后可知的事后压力代理。
- 账户模型尚未处理分红、除权现金流、部分成交、排队和市场冲击。
- 发布包不重新分发第三方行情；复现实验需要取得相同哈希且有权使用的数据快照。

本项目仅用于学习与研究，不连接券商、不自动交易、不构成投资建议。
