# A-Share Quant Lab v0.9.1

v0.9.1 让第一次运行和第一次参与贡献都更容易。研究引擎与 v0.9.0 保持兼容；这一版重点改善跨平台离线演示、双语入门、公开审查入口和文档可靠性，不增加收益承诺，也不连接真实券商。

> Cross-platform offline demo, English onboarding, contributor-friendly review forms, and local Markdown link checks. Start with the [English quick start](../quickstart.en.md).

## 核心亮点

- 新增 `run_demo.sh`、`scripts/setup.sh` 和 `scripts/run_demo.sh`，支持 Linux 与 macOS 一条命令运行确定性的合成数据演示。
- GitHub Actions 新增 Ubuntu 与 macOS 演示冒烟检查，同时继续在 Windows 上覆盖 Python 3.11、3.12 和 3.13。
- 新增中英文快速开始教程、明确的合成数据警告和演示净值图。
- 固定 shell 脚本为 LF 行尾，降低跨操作系统检出后无法运行的风险。

## 贡献与公开审查

- README 与贡献指南增加英文入口，Issue 和 Pull Request 均可使用中文或英文。
- 新增研究完整性与数据质量审查表单，集中收集未来信息、数据来源、成本假设、账本和选择性报告问题。
- 新增纯标准库的 Markdown 链接检查器；测试会离线检查 README、贡献指南和两份快速开始，并定位缺失链接的来源文件与目标。
- 公开保留带有 `good first issue`、`documentation`、`tests` 和 `help wanted` 标签的新手任务，方便首次贡献。

## 快速开始

Windows 用户在项目根目录双击 `run_demo.cmd`，或在 PowerShell 中运行：

```powershell
.\run_demo.cmd
```

Linux 或 macOS 用户运行：

```sh
sh run_demo.sh
```

首次运行会创建 `.venv` 并安装锁定依赖。完成后打开 `outputs/demo_000300_sma_report.html`。该报告必须把数据源标记为 `SYNTHETIC_DEMO_NOT_MARKET_DATA`；演示数值只用于验证可复现性，没有投资含义。

## 验证

- 本地发布门禁通过 Ruff、mypy、源码编译和 377 项 pytest 测试。
- GitHub Actions 覆盖 Windows/Python 3.11、3.12、3.13，以及 Ubuntu 和 macOS 离线演示。
- 发布包在创建前会解压到隔离目录，检查必需文件、命令入口、源码编译和完整测试。
- Markdown 链接检查不访问网络，并忽略外部网址、邮箱链接、页内锚点和图片。

## 安全边界

本项目只用于学习与研究，不连接券商、不发送真实订单、不读取券商账户、不保存券商凭证，也不构成投资建议。演示使用确定性合成数据；历史回测、模拟盘和压力情景均不代表未来表现。

## 源码包与本地数据

Release 资产 `a-share-quant-lab-source-v0.9.1.zip` 不包含第三方行情、DuckDB 模拟账户、锁文件、日志、审计归档或 `outputs/` 用户报告。包内只保留空的 `data/` 与 `outputs/` 目录；用户需要依法取得真实行情，并使用数据集 ID、SHA-256、来源和采集时间核对自己的数据快照。
