# A-Share Quant Lab v0.9.0

v0.9.0 把项目从历史回测推进到可持续运行的本地前向模拟盘。它关注可复现、可审计和失败可见性，不提供收益承诺，也不连接真实券商。

## 核心亮点

- 固定使用 `sh.510300` ETF，运行 SMA 20/60 与 120 日动量两个隔离账户。
- 按 A 股交易约束处理 T+1、整手交易、涨跌停、手续费、印花税、滑点和订单延期/取消/过期。
- 使用追加式 DuckDB 事件账本、哈希链、状态重建和同日双账户原子提交保存模拟记录。
- 提供 `paper-init`、`paper-run`、`paper-status`、`paper-daily` 命令和 Windows 一键入口。

## 审计与研究证据

- 逐日收益归因拆分开盘跳空、原持仓日内变化、交易时点、费用、分红和份额调整，并拒绝无法解释的残差。
- 风险仪表盘展示波动率、最大/当前回撤、最差单日、连续亏损和历史仓位暴露。
- 同期比较现金基准与不复权标的价格基准，校验共享日期和价格路径。
- 保存逐日前向观察历史，并用固定的 20/60/120/252 日里程碑区分样本积累与策略有效性。
- 支持现金分红和份额调整快照，拒绝迟到、冲突或不可重放的企业行动数据。

## 每日自动化

`paper-daily` 会依次更新行情、检查数据健康状态并运行模拟盘。每次运行都会保存不可变 JSON、最新状态和文本日志；失败会返回非零退出码，并在当前 Windows 用户在线时显示本地通知。

双击 `install_paper_daily_task.cmd` 可安装工作日 18:30 的计划任务，双击 `uninstall_paper_daily_task.cmd` 可撤销。安装器拒绝从 `.worktrees` 临时目录注册任务，避免开发目录删除后留下失效路径。

## 快速开始

1. 解压源码包并进入项目目录。
2. 双击 `run_demo.cmd`，首次运行会创建 `.venv` 并安装锁定依赖。
3. 双击 `run_paper_trading.cmd` 初始化或推进模拟盘。
4. 打开 `outputs/default_paper_latest_report.html` 查看最新报告。

需要自动运行时，再双击 `install_paper_daily_task.cmd`。项目需要 Python 3.11、3.12 或 3.13，以及可访问行情源的网络环境。

## 验证

- GitHub Actions 在 Windows 上覆盖 Python 3.11、3.12 和 3.13。
- 发布包会在创建前完成解压、必需文件检查、源码编译、命令入口检查和完整测试。
- 同一交易日重复执行返回 `no-op`，不会重复处理日期或重复生成交易。

## 安全边界

这是研究和教学用途的本地模拟盘：不连接券商、不发送真实订单、不保存券商凭证、不授权真实资金交易，也不构成投资建议。费用、滑点和策略参数均为研究假设；历史回测和模拟结果不代表未来表现。

## 源码包与本地数据

Release 资产 `a-share-quant-lab-source-v0.9.0.zip` 不包含第三方行情、`data/*.duckdb` 模拟账户、锁文件、日志、审计归档或 `outputs/` 用户报告。包内只保留空的 `data/` 与 `outputs/` 目录；用户需要自行依法取得行情，并从自己的第一条账户事件开始前向观察。
