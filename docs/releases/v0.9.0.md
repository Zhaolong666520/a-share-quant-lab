# A-Share Quant Lab v0.9.0

## Highlights

- 新增本地前向模拟盘：固定 `sh.510300` ETF 上的 SMA 20/60 与 120 日动量账户。
- 事件追加、哈希链审计、状态重建与双账户同日原子提交。
- `paper-init`、`paper-run`、`paper-status` 与 Windows 一键入口。
- 中文审计仪表盘、JSON、CSV 和净值/回撤图。

## Safety boundary

这是本地模拟盘，不连接券商、不发送订单、不保存凭证，也不构成投资建议。费用与滑点是教学假设；它不会为账户创建日前的历史行情补写模拟收益。

## Source package

源码包不包含第三方行情、`data/*.duckdb` 模拟账户或 `outputs/` 用户报告。解压后可运行测试和命令帮助，但需要用户自行依法取得行情并从自己的第一条账户事件开始前向观察。
