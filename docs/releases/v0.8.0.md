# A-Share Quant Lab v0.8.0

这一版增加了一个用户能直接看见、同时仍可审计的功能：固定多策略对比。

## 新增

- 买入持有、20/60 日双均线、120 日时间序列动量并列比较；
- 相同数据、切分日期、单边成本和买入持有口径；
- 样本外净值图、中文 HTML、机器可读 JSON 和汇总 CSV；
- `finance-lab compare`、`compare-all` 与 `run_strategy_compare.cmd`；
- 第八课与实验 007 记录。

## 研究纪律

程序固定展示全部三种策略，不根据历史表现自动选择“最好”的规则。动量与均线信号都在收盘
后产生，最早在下一交易日开盘执行；首个样本外交易日前未完成指标预热时会直接拒绝运行。
跨越切分日的单行收益会被排除，避免切分日前的交易被计入样本外结果。

正式对比报告绑定数据集 ID、目标 Parquet 文件 SHA-256、语义数据指纹与健康状态。单边成本
仍是教学假设，不是当前真实交易费率。

## 兼容性

支持 Python 3.11、3.12 和 3.13。源码发布包不包含第三方行情数据。
