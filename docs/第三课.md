# 第三课：为什么一次样本外检验还不够

## 一次切分可能碰巧遇到特殊行情

第二课把历史数据分成开发期和样本外期，但一次切分只回答一个问题：策略在那一段时间表现
如何。某个区间可能刚好是单边上涨、长期下跌或剧烈震荡，不能代表其他市场阶段。

滚动检验把固定策略依次放进多个互不重叠窗口：

1. 首个窗口开始前的数据作为历史信息；
2. 参数始终固定为20日和60日，不在窗口之间重新搜索；
3. 每12个月计算一次策略收益、基准收益、最大回撤和交易次数；
4. 将所有窗口按时间拼接，再计算聚合表现；
5. 后面的行情不能改变已经完成的早期窗口结果。

## 这次为什么不叫“全新样本外证据”

我们已经在实验001中查看过2023年以后的结果。现在再把2021年至今划成多个窗口，只能帮助
诊断策略在不同历史阶段是否稳定，不能让已经看过的数据重新变成未知数据。

真正的新样本外证据只能来自未来尚未发生的行情，或者在研究开始前就严格封存且从未查看的
数据。诚实标记这一点，比报告数字是否漂亮更重要。

## 如何阅读滚动报告

依次回答四个问题：

1. 有多少窗口收益为正？
2. 有多少窗口跑赢买入持有？
3. 亏损是否集中在某类市场阶段？
4. 聚合收益是否依赖一两个异常好的窗口？

如果大多数窗口都没有跑赢基准，就没有理由因为某一个窗口盈利而相信策略稳定。

## “机械执行一致性通过”不等于能够真实成交

当前程序会检查：交易日是否有有效开盘价，信号日期是否严格早于执行日期。这只能排除最基础
的数据和时点错误。它尚未完整模拟：

- 涨停时买不到、跌停时卖不出；
- 停牌与恢复交易；
- ETF分红和申购赎回影响；
- 滑点、印花税、流动性和市场冲击；
- 实盘延迟、订单部分成交与资金容量。

因此，滚动检验仍然是学习工具，不是实盘许可证。
