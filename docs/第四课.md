# 第四课：交易成本为什么会吃掉策略收益

## 一个基点是多少

一个基点（basis point，bps）等于0.01%。本阶段使用5、10、20、50 bps四个**假设单边成本**：

- 5 bps = 0.05%；
- 10 bps = 0.10%；
- 20 bps = 0.20%；
- 50 bps = 0.50%。

“单边”表示买入和卖出分别扣一次。假设单边5 bps，一次完整买入再卖出的名义成本约为10 bps，
还没有考虑资金净值变化和复利。

这些数值不是当前券商佣金、法定税率或实际滑点。不同市场、品种、账户、交易方向和时间可能
适用不同规则；本实验只回答“如果成本更高，策略会退化多少”。

## 为什么交易次数很重要

回测中每次仓位变化都会产生换手：

```text
成本 = 换手比例 × 单边成本
净收益 = 持仓收益 - 成本
```

同一个策略的信号、仓位和交易边数在四个情景中完全相同。只有成本不同，因此成本提高后净
收益不应该反而改善。如果出现改善，通常说明计算或数据对齐有错误。

## 如何阅读压力报告

1. 先看最低成本情景是否已经亏损；
2. 比较最低与最高成本的累计收益差；
3. 检查交易边数是否在所有情景一致；
4. 查看正收益窗口和跑赢基准窗口是否减少；
5. 确认报告显示“收益随成本单调不增加”。

如果最低成本情景都没有优势，就没有必要通过假设更低的成本来美化结果。

## 为什么买入持有基准线可能不变

本项目让策略和基准在首个滚动窗口之前连续运行。买入持有基准在窗口开始前已经建立仓位，
窗口内没有换手，所以压力测试期间不会重复扣入场成本。双均线策略会多次进出，因此受到成本
影响。这是“已有持仓连续运行”的比较，不是每个窗口重新空仓起步。

## 成本压力测试仍然缺少什么

- 买卖方向不同的费用；
- 最低佣金与按股数计算的费用；
- 涨跌停导致无法成交；
- 停牌、部分成交和订单延迟；
- 随成交量变化的滑点和市场冲击；
- ETF分红、股票印花税等品种差异。

因此，本阶段只是从“固定低成本”迈向“成本敏感性分析”，仍不能用于实盘决策。
