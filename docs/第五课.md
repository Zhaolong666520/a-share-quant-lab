# 第五课：不要只相信一组恰好好看的参数

## 什么是参数敏感

双均线策略需要短均线和长均线两个窗口。20/60只是人为指定的一组数字，不是自然定律。如果
20/60表现很好，但19/60、20/59或相邻区域迅速变差，这个结果可能只是历史噪声或偶然巧合。

参数稳健性检验要回答的是：**轻微改变参数后，结论的方向是否大致保持？**

## 本课使用的诊断网格

本项目预先固定九组组合：

- 短均线：10、20、30日；
- 长均线：40、60、90日；
- 参照组：20/60；
- 假设单边成本：5 bps；
- 首个滚动检验日：2021-01-01；
- 每个历史窗口：12个月。

所有组合使用相同的数据日期、滚动边界、买入持有基准和成本。程序还会逐组检查信号只能在
下一交易日执行，避免某组参数因执行方式不同而占便宜。

## 这不是参数优化

优化通常会按历史收益、夏普或回撤挑出一组“冠军参数”。本课不这么做：

1. 网格在看结果前固定；
2. 九组结果全部保留，包括亏损结果；
3. 20/60参照组不会因结果不好而更换；
4. 报告只描述分布，不自动推荐最佳组合；
5. 已经查看过的历史区间仍属于回顾性诊断。

测试的参数越多，偶然找到一组漂亮结果的概率越高。这叫多重比较问题。若只展示最好的一组，
很容易把运气误认为规律。

## 如何阅读热力图

热力图每个格子是一组短/长均线的滚动聚合收益，蓝框标记20/60参照组。依次检查：

1. 九组中有多少组为正收益；
2. 有多少组跑赢相同买入持有基准；
3. 收益中位数是正还是负；
4. 最好与最差组合相差多大；
5. 好结果是否形成连续区域，还是孤立在一个格子；
6. 每组执行一致性检查是否通过。

若大多数格子都亏损，就不应拿表现最好的格子包装成可交易策略。若多数相邻格子方向一致，
也只能说明值得继续研究，不能证明未来会赚钱。

## 本课仍然没有解决什么

- 参数网格仍是人为选择；
- 同一批历史数据已经被多次查看；
- 没有完整模拟停牌、涨跌停、流动性和市场冲击；
- ETF分红和不同品种费用仍不完整；
- 没有使用真正封存、未来才揭晓的数据。

因此，参数稳健性报告是一份“反过拟合体检”，不是选股信号或交易建议。
