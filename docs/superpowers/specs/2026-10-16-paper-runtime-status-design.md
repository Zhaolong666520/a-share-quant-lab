# 每日运行只读诊断设计

2026-10-16：用户已确认运行可靠性方向及本设计，并明确批准实施。

## 范围与接口

新增独立入口 `python -B -m finance_lab.paper_runtime_status --root ROOT --portfolio ID --expected-as-of YYYY-MM-DD`。
预期日期必填，含义是用户要求已经完成估值的交易日；不从工作日、机器日期或计划时间猜测交易日。
新增入口复用 `inspect_paper_operational_status`，不改变旧命令的 schema、状态或退出码。

输出一个 JSON，分别保留底层只读事实、最后成功、最后估值、应用日志中的启动/终态观察、行情标记，
以及 Windows 任务快照。计划的下一时间不是实际运行证据，历史成功不是当前成功。
日志和行情标记均不能确认进程是否仍活着；任务和应用没有共享实例 ID，不自动认定两者精确关联。

Windows 用随包提供的固定 PowerShell 资源，仅调用查询 API。Python 以参数数组启动自己的查询进程，
15 秒超时；查询错误、权限不足、不支持的平台、缺失 PowerShell、无效或过期快照均保留调度未知。
不因调度查询失败抹掉可读的应用与账本事实。任务结果为运行中代码时不能写作进程失败或完成。
可用事件才区分时间触发与手动触发，缺证保持未知，不根据时间形状猜测自然运行。

## 证据与判定

- 归档、行情和账本沿用原只读审计；数据健康不重新生成，报告文件不在本批验收。
- 对固定 `outputs/paper_automation_logs/` 下匹配组合的月日志做有界读取，拒绝链接/异常文件。
  最多 120 个日志文件，每个最多 2 MiB；超限不截断冒充完整扫描。
  按完整组合ID过滤成员，其他合法前缀组合不消耗该120文件配额；目录前缀项总扫描仍最多10,000。
  使用runtime专用Observation子类，不改变旧观察器；仅保留每类最新记录及其并列冲突。
- 只提取规范的启动时间、请求日期、终态及退出码；不输出日志错误原文。
  启动晚于最后完成归档时报告缺少后续归档，终态日志也不能代替可校验的归档。
- 行情 `updating` / `failed` 说明隔离或未完成证据，输出开始时刻、阶段和观察到的时长，
  不判定根因，不自动解锁或回退。未来时间和读取途中变化都使相关证据未知。
- 最后成功请求日期仅使用已验证 schema2 运行身份的 health.as_of_date；旧协议缺字段为未知。
  最后估值日期来自账本 VALUATION。分别与显式预期日期比较，旧成功不能覆盖新失败。
- 总状态 `ok/attention/error` 对应检查命令退出码 `0/1/2`，与系统任务及历史应用退出码分开。
  底层 attention、任何必需未知、输入变化、旧成功、估值落后、未归档启动或隔离均不能返回 ok。
- 始终明确非原子观察、当前健康未核验、任务/应用关联未核验、非真实资金准入。
- 系统快照不接受未来采集时刻，日志最新请求日期不接受晚于上海观察日。
  stdout在读取时最多保留64KiB加一个越界检测字节，stderr丢弃；超限/15秒超时只回收自有查询进程。
  固定查询脚本不得启动继承输出管道的后代；不把该边界泛化为任意外部命令监管器。

## 边界与验证

不触发行情、不生成报告、不写正式根、不创建锁、不修改调度、权限、电源、策略或实验参数，
不新增自动补跑/监控。用户此前单次手动运行授权不复用为本批的运行授权。

测试覆盖：旧成功及新启动、失败和 no-op、显式预期日期、旧协议、未来时间、损坏/超限日志、
输入变化、WAL/账本不可用、系统权限/超时/缺工具、任务运行中和非零结果、触发来源未知、
CLI 单 JSON/0-1-2 退出码、无业务写入及禁止写流水线导入。真实根只读观察不替代隔离测试。
不提交或推送代码，保留用户原先未跟踪的迁移计划。
