# P2.2m：`all` 行情提交后回测报告失败

## 边界

仅处理 `all` 已返回成功的行情更新结果、开始逐标的生成回测报告后发生的 `ReportWriteError`。行情更新本身失败或部分来源失败仍沿用现有非零退出行为；更新过程在返回前中断、配置损坏和其他异常暂不归入本错误码。

## 失败契约

- 返回码 1，输出单个 JSON 失败对象，不先打印一次“行情更新成功”或“报告已生成”。
- `error_code=report_write_failed_after_data_commit`、`stage=write_report`、`data_committed=true`、`report_batch_complete=false`。
- 记录 `market_update_status`、已确认完成的报告、失败标的；当前报告文件状态仍标为 `unknown`，不假设多文件写入已回滚。
- 保留已提交行情和先前成功的报告。建议先修复写入环境、核验已完成报告，再单独运行 `backtest` 补齐失败标的，不盲目重复抓取行情。
- 成功路径仍输出原有行情更新 JSON 和逐报告提示，只延后到整批报告成功后打印。

## 验证

用临时目录及合成行情模拟行情提交，在报告 JSON 原子替换处注入磁盘故障；检查非零退出、单个失败 JSON、行情 Parquet 字节未变化、无新完成标记且不泄露底层异常。另用两个合成标的检查先前完成报告被列出、失败标的不被算作完成。未请求真实行情，也未修改真实账户。

## 后续

针对模拟盘“账本已提交但报告失败”的恢复与重试语义单独实施，避免把 `all` 的行情提交语义套到账本上。
