# P2.2h 历史研究报告文本文件原子替换

依据：[P2.2 命令失败语义设计](../specs/2026-09-25-cli-failure-semantics-design.md)。本批覆盖基础回测、账户账本、样本外、滚动检验、成本压力、参数稳健性、执行可行性和多策略对比八类历史研究报告的 HTML/JSON 文件。前向模拟盘与图像/CSV 留待独立方案。

1. 用临时样本外报告写故障注入测试：HTML 与 JSON 的目标替换失败时，已存在的目标字节不变、临时文本文件清理、异常向上报告；成功路径维持原内容。
2. 八类报告复用现有 `write_text_atomic` 写 HTML/JSON。仅单文件原子替换，不承诺 HTML+JSON 成对事务、图像/CSV 原子性或断电持久性；失败时不删除旧产物。
3. 跑定向与全量测试、Ruff、mypy、编译、依赖、Markdown 链接及差异检查，记录结果。
