# P2.2b 命令参数预检实施计划

依据：[P2.2 命令失败语义设计](../specs/2026-09-25-cli-failure-semantics-design.md)。本批仅处理 CLI 解析阶段，不运行真实抓取或报告。

1. 在临时/无数据环境中补解析失败测试，覆盖非规范日期、非有限或负成本、零/负/重复窗口；确认失败在业务分派前发生，退出码非零。
2. 对 `_parse_date`、`_parse_costs`、`_parse_windows` 做最小严格化。保持既有合法参数与默认值兼容；错误提示只解释约束，不回显用户输入全文。
3. 定向和全套测试、Ruff、mypy、文档链接与差异检查；记录准确结果。缺文件和写入失败另起批次。

状态：本批已通过本地验收。全套收集 700 项：699 项通过、1 项因系统不允许创建符号链接跳过；Ruff、mypy（45 个源文件）、compileall、pip check、47 份 Markdown 链接与 `git diff --check` 通过。解析失败发生在业务分派前；未测试或声称全部 CLI 数值参数都已覆盖。未联网、未改动真实行情、未合并/推送/发布。
