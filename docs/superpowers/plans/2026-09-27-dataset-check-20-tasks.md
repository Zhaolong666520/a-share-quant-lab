# P1.2b.2c.4：数据集核验命令（20 项清单）

## 目标

增加只读 `dataset-check --expected-dataset-id <64位ID>`。它与研究命令共用身份/健康门禁，成功时输出机器可读 JSON；失败时保持安全的非零诊断。它不抓行情、不生成报告、不更新正式数据。检查结果只代表检查当刻；后续研究仍须逐命令传入同一预期 ID。
