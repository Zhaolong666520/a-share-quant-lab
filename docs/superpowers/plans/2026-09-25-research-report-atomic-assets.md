# P2.2i 历史研究报告图表和 CSV 原子替换

依据：[历史报告文本原子替换](2026-09-25-research-report-atomic-text.md)与[命令失败语义设计](../specs/2026-09-25-cli-failure-semantics-design.md)。本批覆盖同八类历史研究报告中的 PNG 图表及 CSV 数据文件，前向模拟盘和整组事务化不在范围内。

1. 对临时样本外报告分别注入 PNG/CSV 目标替换失败，验证旧目标字节不变、临时文件清理、异常上报；另测临时文件写入中途失败时也清理。
2. 加一个接收临时路径写入函数的原子文件工具；PNG 显式指定格式，CSV 保留 UTF-8 BOM 与原字段顺序。八类报告逐文件复用，失败不删除旧报告。
3. 跑定向、全量测试与静态检查。明确单文件原子替换不保证 HTML/JSON/PNG/CSV 成组切换或断电持久性。

状态：已完成。八类历史研究报告的 PNG/CSV 均通过临时文件写入后逐文件替换，
图像生成失败也会关闭 Matplotlib figure。样本外报告分别对 PNG/CSV 注入目标
替换失败，并验证 PNG 文件头和 CSV BOM；通用写入器的中途失败清理也已测试。
定向测试 61 个通过；全量收集 756 个，755 个通过、1 个因 Windows 符号链接
权限跳过。Ruff、mypy、编译、`pip check`、Markdown 链接和 `git diff --check`
均通过。所有故障注入只使用临时项目。
