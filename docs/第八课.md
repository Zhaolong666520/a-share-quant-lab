# 第八课：固定多策略对比

这一课不追求“找到历史收益最高的策略”，而是学习如何把不同规则放在同一把尺子下比较。

## 本课新增什么

项目固定比较三种简单规则：

1. 买入持有：从可执行的首日开始保持满仓；
2. 20/60 日双均线：短均线高于长均线时持有，否则空仓；
3. 120 日时间序列动量：当日收盘价高于 120 个交易日前收盘价时持有，否则空仓。

三个策略使用相同的数据文件、2023-01-01 切分、单边 5 bps 假设成本和收益日期。所有信号
都在收盘后生成，最早于下一交易日开盘执行。程序完整保留三个结果，不根据历史收益自动选出
所谓“最佳策略”。

开发期只接收切分日前已经实现的收益；样本外只接收交易日不早于切分日的收益行。因此，从
切分日前一个交易日跨到切分日后第一个交易日的那一行会被明确排除，不会偷渡进任一阶段。

## 一键运行

双击根目录的 `run_strategy_compare.cmd`。已有环境时也可以在 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -m finance_lab.cli compare-all `
  --split-date 2023-01-01 --short 20 --long 60 `
  --momentum-lookback 120 --cost-bps 5
```

每个标的会生成四个文件：

- `*_report.html`：中文汇总报告；
- `*_equity.png`：样本外净值对比图；
- `*_metrics.json`：完整机器可读设置与指标；
- `*_summary.csv`：便于继续分析的策略汇总表。

正式命令会先生成数据清单、检查目标文件的健康状态，再把数据集 ID 与文件 SHA-256 写进
报告。文件在检查后发生变化时，程序会中止，避免报告指标和数据身份错配。

## 为什么要固定顺序和参数

如果看完结果后把 120 日改成 118 日、把 20/60 改成 17/53，直到曲线最好看，这就不再是
验证，而是把历史噪声当成规律。这里的参数是教学基准，不代表最优，也不构成交易建议。

比较报告首先回答四个问题：

1. 三种规则是否使用同一段样本外日期？
2. 买入持有基准和成本口径是否完全一致？
3. 收益差异是否伴随更大的回撤、更多交易和更低持仓比例？
4. 某个结果是否只是在已经看过的历史区间里偶然更好？

## 当前边界

- 这是日线、开盘到下一开盘的教学模型；
- 单边 5 bps 是假设情景，不是当前真实费率；
- 指数只能做信号研究，不能把指数点位当成可成交证券；
- 不复权数据没有单独建模分红与除权现金流，不能称为长期总回报；
- 本课使用的历史区间已经被查看，只能称为回顾性诊断。

下一步若要添加新策略，应先在新的实验文档中写清经济假设、固定参数和验证边界，再查看
历史结果。
