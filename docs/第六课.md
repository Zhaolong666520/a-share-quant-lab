# 第六课：回测下单不等于真实成交

## 为什么要检查执行可行性

基础回测默认信号在下一交易日开盘成交。这个时间顺序避免了未来函数，但仍隐含一个很强的
条件：每次想买或想卖时，都能立刻按开盘价完成交易。真实市场可能停牌、排队、流动性不足，
或者价格快速跳动。因此，正确的信号也可能得到不同的仓位路径和收益。

本课不尝试用日线“还原”真实盘口，而是用两个简单压力情景问：如果成交没那么顺利，结论会
怎样变化？

## 三个固定场景

1. **理想次日开盘：**收盘形成信号，下一交易日开盘成交，与基础回测完全一致；
2. **统一额外延迟：**所有目标仓位再延迟一个交易日，用来观察时点敏感性；
3. **事后日线阻塞代理：**零成交量视为停牌代理；全天只有一个价格且相对前收向上跳空至少9.5%，
   视为潜在买入阻塞；向下跳空至少9.5%，视为潜在卖出阻塞。

9.5%只是预先固定的教学阈值，**不是当前涨跌停规则**。最高价、最低价和全天成交量是在收盘后
才完整获得，因此本代理是事后分类，不是开盘时可用的因果信号。不同证券、日期、板块、交易
状态和复权口径可能适用不同制度，单根日K线也无法告诉我们订单队列与成交概率。

## 受阻后怎样处理

执行状态机遵守四条规则：

- 切分日前三个场景都按理想成交初始化，从首个样本外交易日起才施加压力，保证起始状态相同；
- 买入受阻时继续持有现金，卖出受阻时继续持有原仓位；
- 受阻当天换手为零、成本为零；
- 只要目标仓位没有改变，下一交易日继续尝试；
- 策略信号日期必须早于成交尝试日期；事后日线代理则明确使用当日收盘后完整K线，只用于历史
  可行性分类，不能用于当日开盘决策。

报告会保留每次尝试、阻塞原因、成交结果、仓位变化与成本，并运行逐行一致性检查。

## 怎样阅读结果

先比较“统一额外延迟”和“理想次日开盘”的累计收益差及仓位不同天数。若只多等一天就使
结果剧烈变化，策略对执行时点敏感。再看事后日线代理命中了多少次实际下单：

- 有阻塞并改变结果，说明理想成交假设确实乐观；
- 没有阻塞，不代表真实市场一定能成交，只表示这段日线数据和策略下单没有命中这组保守代理；
- 三个场景接近，也只能说明通过了这一层压力测试，不能证明可实盘。

沪深300指数本身不能直接交易。指数报告用于研究信号与数据流程；真实执行必须换成可交易的
ETF、期货或其他工具，并重新核对费用、跟踪误差、合约规则与流动性。

## 本课仍未解决什么

- 没有逐笔订单簿、排队位置和部分成交；
- 没有建模盘口滑点、冲击成本与委托撤单；
- 事后日线代理不是交易所规则引擎或因果成交模型；
- ETF分红、税费和申赎影响仍不完整；
- 已看过的历史区间仍是回顾性诊断，不是新的未来证据。

因此，执行可行性报告是一份“理想成交假设体检”，不是实盘许可或投资建议。
